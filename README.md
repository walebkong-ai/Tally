# Tallyo

Tallyo is a Swift-generated website for tracking daily word and puzzle games with friends.

## Build

```sh
swift run tallyo-site
```

The build writes the deployable site to `dist/`.

## What is in this version

- Daily game tracker for games like Wordle, Zip, Krillion, and Queens
- Friend leaderboard
- Spoiler-safe answer sharing
- Add-friend and add-game flows
- Browser-local saved data for the first prototype
